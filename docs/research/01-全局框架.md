# 01-全局框架（TopBar / Footer / 404，2026-08-09 重建）

## 一、TopBar（全站唯一横条，App.tsx Nav 渲染）

| 项 | 官方（2026-08-09 实测） | PureGit（Nav.tsx） | 差异 |
|----|------|------|------|
| 高度 | 64px（h-16 级） | 56px（h-14） | ❌ 高 8px |
| 左 | ☰ 菜单 + GH Logo + 面包屑 | Logo + PureGit 文字 | ⚠️ 无 ☰/面包屑 |
| 中 | 搜索 **pill 按钮** → Quick Search dialog（placeholder `Search or jump to...`，`/` 快捷键） | 内联 Input 表单（回车提交） | ❌ 无 dialog/`/` 快捷键/建议 |
| 右组 | Copilot + Agents + `+ Create new▾`（8 项 3 组）+ issues + PRs + repos + 🔔（未读红点）+ 头像 | CreateNewMenu（4 项）+ issues/PRs/repos/gist/通知 5 图标 + 头像菜单（3 项） | ⚠️ Create 4 vs 8；用户菜单 3 vs 官方 15 项面板 |
| 手机 <768 | 只留 6 项 + ☰ drawer | 无响应式折叠 | ❌ |

**决策**：去杂项保留现状（内联搜索 + 4 项 Create）；高度 56px 为 sticky 锚点计算基准（topbar 57px → top-20=80px），**勿改**。

## 二、Footer（AppFooter）

- **官方**：GitHub mark + 仓库链接 + Star 数；右侧 status/terms 链接；© 2026 GitHub, Inc.
- **PureGit**（2026-08-08 修订）：左 = 项目仓库链接（mark + PureGit + Star 简写）；右 = GitHub API 状态点 + 额度剩余（Plug 图标 + 简写）；无 copyright。
- **一致 ✅**（简化，保留官方心智）。
