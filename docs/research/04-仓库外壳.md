# 04-仓库外壳（RepoHeader / About 显示范围 / 仓库首页，2026-08-09 重建）

## 一、RepoHeader（仓库级头部，RepoLayout 渲染）

| 项 | 官方（2026-08-09 实测） | PureGit | 差异 |
|----|------|------|------|
| 仓库名行 | 头像 + owner/repo 链接 + Public/Private 徽标；右侧 Watch/Fork/Star | 头像 + owner/repo + 徽标 + StarForkButtons | ✅ 一致 |
| tab 栏 | 48px **sticky 吸顶** + 图标 + **计数**（Issues/PRs）+ 活跃橙色线 | border-b 非 sticky + border-b-2 高亮 + **无计数** | ❌ 非 sticky/无计数/高亮色 |
| tab 集 | Code/Issues/PRs/Agents/Actions/Projects/Wiki/Security/Insights + Settings(owner) + Discussions(enabled) + Releases(有) | Code/Issues/PR/Discussions/Actions/Projects/Wiki/Security/Insights/Releases/Settings | ⚠️ 无 Agents；Security vs "Security and quality" |

**决策**：tab 非 sticky 与无计数为去杂项（sticky 吸顶在 RepoHeader 实现成本高且易引入滚动冲突）；高亮色沿用站点 primary。

## 三、仓库首页 CodeIndex（/）

- **分型**：G 型两栏（主列 + 右 About 320px，lg 起）；<992 About 隐藏。
- **区块**：操作行（`[master▾][Branches][Tags] | [Add file▾][Code▾]`）→ Latest commit 行 → **文件列表 table 3 列（Name/Last commit msg/Last commit date）** → README 渲染 → About 侧栏（About/Resources/Stars/Watchers/Forks/Report/Releases/Packages/Used by/Contributors）。
- **PureGit**：PageLayout right About ✅；操作行 ✅（分支 + Go to file + 新增 + Code 克隆下拉，缺 Branches/Tags 链接、Add file 为图标非下拉）；**文件列表仅图标+名称+大小（缺 commit msg/date 列）**；README ✅。
- **搜索框**：无（Go to file 在操作栏）。
- **差异**：文件列表 3 列化待做（Name + commit msg + date）；Add file 下拉待做。
