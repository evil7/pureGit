# 03-用户级页面（用户主页 / 仓库 / 组织 / Gist / 个人设置，2026-08-09 重建）

## 一、用户主页（/login）

- **分型**：E 两栏（左资料卡 260 + 右内容）。
- **顶部 tab（UnderlineNav 带计数）**：Overview / Repositories / Projects / Packages / Stars。
- **左卡**：大头像（方形圆角）+ 状态徽章 + 名字/@login/代词 + Edit/Follow + bio + followers/following + 公司/位置/网站 + 组织头像列表 + Achievements。
- **右**：Pinned（2 列网格）→ 贡献热力图 → Contribution activity。
- **PureGit（2026-08-09 方案 A 已对齐）**：PAGE_SHELL + PageLayout（left 260 资料卡 nav sticky）+ 右 UnderlineNav 下划线高亮 tabs（text-lg 同标题字号 + 图标）——用户页 仓库/Star、组织页 仓库/成员（用户去概览，2026-08-09）；仓库 = 完整列表；Star = 懒加载星星列表（数量随主页查询一次拿到：GraphQL starredRepositories.totalCount / REST Link 头）；统计权限感知：公开数 `repositories(visibility:PUBLIC).totalCount` 恒显（FolderGit2），私有数 `totalCount-公开数>0` 时显示（Lock，API 自动处置）；状态/代词/组织为 GraphQL 字段（REST 降级缺）。
- **差异**：260 vs 官方 296；缺贡献图/activity；Achievements/Highlights 无公开 API 省略（用户确认）；断点 md vs 官方 992。
- **PageLayout 用法**：`left={{node:data ? <ProfileSidebar/> : <SidebarSkeleton/>, width:260, sticky:"nav"}}`（node 内三目）。

## 二、用户仓库列表（/login?tab=repositories）

- **分型**：E 两栏（左卡同主页 + 右列表）。
- **区块**：tab（Repositories 计数）→ 工具条 Type/Language/Sort + New → 仓库行（Forked from + desc + topics + 语言·License·Updated）。
- **PureGit**：❌ 无独立路由（用户主页直接渲染 Pinned + 仓库列表）；「我的仓库」= 全局 /repositories（单栏 + 工具条）。
- **差异**：缺 ?tab=repositories 路由 + 工具条。**PageLayout 复用同一左卡组件 + 不同中栏**（官方心智：同左卡跨 tab 复用）。

## 三、组织主页（/orgs/:org）

- **分型**：E 两栏（左卡 260 + 右内容）。
- **tab**：Overview / Repositories / Projects / Packages / People。
- **左卡**：组织名 + desc + Verified 徽章 + Sponsor + followers + 网站 + README 链接。
- **右**：Pinned → Repositories（工具条 + 仓库行 + commit 活动图）→ People → Sponsoring → Top languages → Most used topics。
- **PureGit（2026-08-09 已对齐）**：与用户页同构（PageLayout left 260 卡 + 右 UnderlineNav 下划线 tabs 仓库/成员）；成员 tab = 成员列表懒加载（匿名 REST 公开成员，认证 GraphQL membersWithRole）；统计权限感知：公开仓库恒显、私有数按权限（API 自动）、成员数仅认证显示（Organization 无公开 members 字段）。
- **差异**：缺 People 工具条/Sponsoring/Top languages/贡献图；Achievements 组织本无。
- **PageLayout 用法**：同 E 型（与用户页共用左卡模式）。

## 四、Gist 列表（/gist）

- **分型**：**E 两栏**（左用户卡 296 + 右列表）——2026-08-09 单栏→两栏对齐。
- **独立 Gist TopBar**：Logo + Search Gists + All gists + Back to GitHub + Create new gist。
- **左卡**：头像/名字 + followers/following + View GitHub Profile 按钮。
- **右**：Type: All▾ + Sort + gist 行（files/forks/comments/stars + user/filename + Secret/Public + 代码预览）。

- **PageLayout 用法**：`left={{node:user?<卡/>:<骨架/>, width:260, sticky:"nav"}}`。

## 五、个人设置（/settings/*）

- **分型**：D 两栏（左导航 ~296 + 右表单）。
- **顶部**：name (login) settings + Switch settings context 下拉。
- **左导航（20+ 项分组）**：Public profile/Account/Appearance/Accessibility/Notifications → Billing/Emails/SSH and GPG keys/… → Blocked users → Repositories/Saved replies → Security → Developer settings。
- **右**：表单区块（Profile/Account/…）。
- **PureGit（2026-08-09 已对齐 PageLayout）**：PAGE_SHELL + PageLayout（left 240 用户卡+导航 6 项+官方外链 nav sticky）+ 内容 `contentClassName="max-w-230"`。
- **路径（2026-08-09 修正）**：`blocked_users`/`saved_replies`（下划线，官方）+ 旧连字符兼容重定向；`appearance` → `preferences` Navigate 兼容。
