# 00-全站布局分型总览（GitHub 官方 重建）

> 目的：从 GitHub 官方全部页面中提取**不重复的布局形态**，分型建模；供 `PageLayout` 三栏模型与各页复刻对照。
> 方法：浏览器逐页实测（audit-repo/global/detail 三份，见 session memory）+ 历史 research 参考。
> **结论**：官方全部页面 ≤ 三栏 = `左栏(可选) + 主内容 + 右栏(可选)`，任一栏不渲染即退化。PageLayout 一组件全覆盖。

## 一、分型总表（A~H，共 36 页全覆盖）

| 分型 | 结构 | 侧栏宽 | sticky | 页面 |
|------|------|--------|--------|------|
| **A** | 全宽单列 | — | — | 新建页（Issue/PR/Discussion/仓库/Gist）、Pulls 列表、全局 Issues 总览、Wiki 编辑、404 |
| **B** | 左文件树+内容 | 320(树)/273(edit) | 工具型限高（SIDEBAR_STICKY_SCROLL） | tree / blob / edit / new（文件编辑） |
| **B+** | 左树+内容+右面板 | 320/344 | 工具型 | blob（symbols/outline 面板） |
| **C** | 左过滤/导航+列表 | 239~315 | 工具/导航 | Issues 列表、全局 Pulls、通知页、Projects（左 Issues sidebar） |
| **D** | 左导航+内容 | 296/256/200 | 导航型（SIDEBAR_STICKY） | 设置页、Insights、Actions run/job |
| **E** | 左资料卡+内容 | 296 | 导航型 | 用户主页、组织主页、用户仓库、Gist 列表 |
| **F** | 内容+右 metadata | 296/320 | 导航型 | Issue 详情、PR 详情、Discussion 详情、新建 Issue |
| **G** | 内容+右 About | 320 | 导航型 | 仓库首页、根 tree（lg 起） |
| **H** | 三栏 | 左336+右312 | 混合 | Dashboard（xl 起） |

> **PageLayout 映射**：`left={node, width, sticky, breakpoint, hidden}` + `right={...}` + `contentClassName`。
> - A 型：不传 left/right（单列）
> - B/B+：left 树（sticky="tool"，md 240→lg 320）+ 可选 right 面板（sticky="none" 随内容滚动）
> - C/D/E：left（sticky="nav"）
> - F/G：right（sticky="nav"）
> - H：left + right

## 三、断点汇总（官方 → PageLayout breakpoint）

| 断点 | 场景 | 页面 |
|------|------|------|
| md(768) | 左导航（D）、右 metadata（F）生效 | 设置 / Issue·PR 详情 |
| lg(1024) | 左树、About（G）生效 | blob / 仓库首页 |
| ~992 | 搜索/用户主页两栏 | 官方实际门槛（PureGit 用 lg 近似） |
| xl(1280) | 三栏生效 | Dashboard |

## 四、sticky 两态（官方 → PageLayout sticky 参数）

| 状态 | 含义 | 常量 | 场景 |
|------|------|------|------|
| nav | 纯吸附（超高裁切） | `SIDEBAR_STICKY` | 左导航 / 右 metadata / About |
| tool | 限高内滚 | `SIDEBAR_STICKY_SCROLL` | 过滤栏（可折叠）、blob 文件树（简化：原通底 `SIDEBAR_FILL` 并入本态，树底留 32px 余量） |
| none | 不 sticky（随内容滚动） | — | blob symbols/outline 面板 |
