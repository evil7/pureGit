## 一、Dashboard 首页（/）

- **分型**：H 三栏（xl 起：左 336 + 中 900 + 右 312）；登出单列。
- **左栏**：Account 卡 + Top repositories（搜索框 `Find a repository…` + Show more）。
- **中栏**：Copilot 输入区（去杂项）→ H2 Feed + Filter → 事件流。
- **右栏**：Explore 卡（去杂项）。
- **PureGit**：`PAGE_SHELL` + PageLayout（left 300 tool sticky lg + 移动端折叠）+ 中栏（Feed/热点 tab + 周期 SegmentedControl）；**无右 Explore（去杂项）→ 两栏**。

- **PageLayout 用法**：`left={token ? {node:<SidebarContent/>, width:300, sticky:"tool", breakpoint:"lg", className:"hidden lg:block"} : undefined}` + 移动端折叠 div。

## 二、全局搜索页（/search）

- **PureGit（2026-08-09 完全重设计，用户拍板：极简、不遵循官方）**：布局定稿——**第一行**搜索框 + 按钮 → **过滤 chips 行紧挨 input 下方**（语言 datalist 可输入+下拉 + Star 数/Fork 数/创建日期/Topic/许可证/已归档；点击展开 inline 输入/选择，回车即 `key:value` 加入输入框 q）→ **结果面板 tabs（UnderlineNav 下划线高亮：active `border-b-2 border-foreground`，排序下拉在 tabs 横线最右）**。
- **设计决策**：仓库 / 用户·组织用 **tabs 自由切换**（`?type=users` URL 驱动，各自独立 Pager 20 条/页）；语言并入过滤项（可输入任意值 + datalist 下拉 11 种）；**分页最多 99 页**（GitHub 官方搜索仅开放前 100 页）；去语法高亮保持纯粹；去掉侧栏/tab 计数。
- **API 结论**：REST /search 与 GraphQL search 的 `q` 参数**原生支持全部 qualifier**（服务端解析）；**REST /search 不解析 q 内 `sort:` qualifier** → 需提取映射到独立 sort 参数（修复，GraphQL 路径原生生效）。
- **官方（2026-08-09 调研记录，旧方案已弃用）**：左栏 Languages + Advanced 折叠 + 类型 tab 7 项带计数；搜索框聚焦时 qualifier token 彩色高亮；Sort 按类型区分；分页 100 页上限——全部**不再遵循**（官方太繁杂，不符合极简要求）。

## 三、全局 Issues 总览（/issues/{tab}）

- **分型**：**A 单栏**（无侧栏；官方刻意用顶部 UnderlineNav 而非左导航）。
- **区块**：4 tab（Assigned/Created/Mentioned/Recent）+ New issue（右上）+ token 化搜索框（预填 `is:issue state:open archived:false assignee:@me sort:updated-desc`）+ Sort。
- **PureGit**：NavPageShell 单栏 + 顶部 Tabs 4 项（URL /issues/:tab）+ RepoSearchInput（前端过滤）+ 卡片列表。
- **差异**：缺 New issue/Sort/Views（去杂项）；搜索前端过滤 vs token 化。
- **PageLayout 用法**：不传 side（单列）。

## 四、全局 Pulls 总览（/pulls/{tab}）

- **分型**：**C 两栏**（左导航 ~256 + 右列表）。
- **左导航**：Inbox/Authored/Assigned/Involves/Reviews + Views。
- **右**：H1 Inbox + Select repositories + Filter by age + PR 行。
- **PureGit**：PAGE_SHELL + PageLayout（left 240 PULL_NAV 5 项 nav sticky）+ 右 PR 卡列表。
- **差异**：240 vs 256；缺 Select repos/Filter by age/Views；无分页。
- **PageLayout 用法**：`left={{node:<nav PULL_NAV/>, width:240, sticky:"nav"}}`。

## 五、通知页（/notifications）

- **分型**：**C 两栏**（左 Folders/Filters/Repositories ~315 + 右列表）。
- **左导航**：Folders（Inbox/Saved/Done）+ Filters（reason:assign/participating/mention/…）+ Repositories。
- **右**：Inbox/Saved/Done tab + Manage notifications + 通知列表（query 过滤）。
- **PureGit（2026-08-09 单栏→两栏对齐）**：PAGE_SHELL + PageLayout（left 240 Folders+Filters nav sticky）+ 右标题 + Mark all + 邀请区 + 通知卡列表。
- **搜索框**：无（query 过滤）✅。
- **PageLayout 用法**：`left={{node:<nav Folders/Filters/>, width:240, sticky:"nav"}}`。
